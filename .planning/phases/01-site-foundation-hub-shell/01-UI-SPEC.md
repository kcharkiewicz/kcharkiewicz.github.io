# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Site Foundation + Hub Shell.
> Generated by gsd-ui-researcher. Consumed by gsd-planner, gsd-executor, gsd-ui-checker.

---

## Scope Note

This contract covers three page types only: **hub landing** (`/index.html`),
**game page** (`/games/where-winds-meet/index.html`), and the **spawn-timer stub**
(`/games/where-winds-meet/tools/spawn-timer/index.html`).

The timer's interactive behavior is Phase 2. Do not design or implement any
interactive timer controls in this phase.

## Color Contract

Base palette is a **neutral dark ink** with two accent layers: a neutral-only hub
layer and a jade+gold overlay for Where Winds Meet pages.

### Base Tokens (defined in `/shared/theme.css`)

| CSS Custom Property | Value | Role |
|---------------------|-------|------|
| `--color-bg` | `#0f1115` | Page background — 60% dominant |
| `--color-surface` | `#1a1d23` | Cards, header, breadcrumb band — 30% secondary |
| `--color-surface-raised` | `#22262f` | Hover state on cards (lifted surface) |
| `--color-border` | `#2a2e38` | Subtle dividers, card edges |
| `--color-text-primary` | `#e8e4d8` | Body copy, headings — parchment-neutral |
| `--color-text-secondary` | `#9a9690` | Muted labels, tool-count line, breadcrumb separators |
| `--color-accent` | `#3fb98f` | Overridden per game — neutral hub default is same jade (see note) |
| `--color-accent-secondary` | `#d4af37` | Overridden per game — hub default is same gold |

> Note: Hub landing (`/index.html`) carries no game identity, so `--color-accent`
> is left at its CSS-file default value without any game-specific override block.
> The hub card for WWM uses the game accent only inside its own card element via
> a scoped override (see Per-Game Accent Mechanism below).

### Per-Game Accent Mechanism

Game pages add a scoped override at the top of their `<body>` or on a wrapper
element using a `data-game` attribute:

```css
/* In /shared/theme.css — game accent layers */
[data-game="where-winds-meet"] {
  --color-accent:           #3fb98f;  /* jade — locked D-02 */
  --color-accent-secondary: #d4af37;  /* gold — locked D-02 */
}
```

Every Where Winds Meet page sets `data-game="where-winds-meet"` on `<body>`.
Hub landing does NOT set this attribute; it remains neutral.

### WCAG AA Verification (Claude-computed)

| Foreground | Background | Approx. Ratio | Result |
|------------|------------|---------------|--------|
| `#e8e4d8` | `#0f1115` | ~14.1 : 1 | AAA |
| `#9a9690` | `#0f1115` | ~4.9 : 1 | AA |
| `#9a9690` | `#1a1d23` | ~4.3 : 1 | AA |
| `#3fb98f` | `#0f1115` | ~6.3 : 1 | AA (normal text) |
| `#3fb98f` | `#1a1d23` | ~5.5 : 1 | AA (normal text) |
| `#d4af37` | `#0f1115` | ~6.7 : 1 | AA (normal text) |

All combinations meet WCAG AA. Accent colors are additionally permissible as
decorative borders and icons where contrast is supplementary.

### 60 / 30 / 10 Split

| Split | Color | Elements |
|-------|-------|----------|
| 60% dominant | `#0f1115` | All page backgrounds |
| 30% secondary | `#1a1d23` | Header band, card surfaces, breadcrumb strip |
| 10% accent | `#3fb98f` / `#d4af37` | Card top border (jade), active/hover card border, breadcrumb active segment, favicon motif fill |

**Accent reserved for exactly:**
1. Top border on game cards (3px solid `--color-accent`, jade)
2. Card border on hover (full border shifts to jade)
3. Active breadcrumb segment text color
4. Cover-art SVG placeholder fill / gradient
5. Favicon motif fill

Accent is NOT used for: body text, page background, card body, breadcrumb separators,
muted labels, the header title.

## Spacing Scale

All values are multiples of 4. Declared as CSS custom properties in `/shared/theme.css`.

| Token | CSS Property | Value | Usage |
|-------|-------------|-------|-------|
| xs | `--space-xs` | 4px | Icon gaps, inline tag padding |
| sm | `--space-sm` | 8px | Breadcrumb segment gap, tool-count padding |
| md | `--space-md` | 16px | Card internal padding, header padding |
| lg | `--space-lg` | 24px | Card grid gap, section vertical padding |
| xl | `--space-xl` | 32px | Page horizontal padding (desktop) |
| 2xl | `--space-2xl` | 48px | Vertical rhythm between major sections |
| 3xl | `--space-3xl` | 64px | Page top/bottom breathing room |

Exceptions:
- Breadcrumb strip vertical padding: 12px (3 × 4) — between sm and md, intentionally compact.
- Minimum touch target size: 44px height on any clickable element (card, breadcrumb link). This is a floor constraint that overrides spacing tokens on small viewports.

## Typography

System font stack only — no external font loads. Declared in `/shared/theme.css`.

| Role | CSS Property | Size | Weight | Line Height | Usage |
|------|-------------|------|--------|-------------|-------|
| Body | `--text-body` | 16px | 400 | 1.5 | General paragraph copy, stub page description |
| Label | `--text-label` | 14px | 400 | 1.4 | Tool-count line ("1 tool"), breadcrumb segments, muted metadata |
| Heading | `--text-heading` | 20px | 600 | 1.2 | Game name on card, game page `<h1>`, stub page `<h1>` |

`font-feature-settings: "kern" 1` applied globally for optical kerning.

## Layout Contracts

### Hub Landing (`/index.html`)

Structure (top-to-bottom):
1. **Header strip** — `--color-surface` background, `--space-md` vertical padding.
   Contains site title "Game Tools Hub" at Display size. No navigation links in header
   (breadcrumb is the navigation pattern; hub root has no ancestors).
2. **Game-card grid** — immediately below header, `--space-2xl` top padding.
3. **Footer** (optional — see below).

**Card grid columns:**
```css
display: grid;
grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
justify-content: center;        /* single card stays centered, not left-flush */
gap: var(--space-lg);           /* 24px */
max-width: 960px;
margin-inline: auto;
padding-inline: var(--space-xl);  /* 32px sides on desktop */
```

Single-card behavior: with `auto-fill` + `minmax(280px, 1fr)`, a single card
on a 600px+ viewport occupies the full column width (up to 960px max). On mobile
(<600px) the grid is a single column and the card is full-width. Neither case
produces a lonely-looking isolated card.

### Game Card

Structure (vertical stack inside the card):
1. Cover art panel — fixed height 160px, `--color-surface-raised` background,
   SVG placeholder centered with `object-fit: contain`.
2. Game name — Heading size, `--color-text-primary`, `--space-md` padding.
3. Tool count — Label size, `--color-text-secondary`, no top padding (sits directly
   under game name with `--space-xs` gap).

Card styling:
- Background: `--color-surface`
- Border: 1px solid `--color-border` (default); top border: 3px solid `--color-accent`
- Border-radius: 8px
- On hover: border becomes 1px solid `--color-accent` (all sides); background
  transitions to `--color-surface-raised`; transition duration 150ms ease.
- Card is the full clickable target — `<a>` wraps the entire card.
- Minimum card height: 220px.

### Game Page (`/games/where-winds-meet/index.html`)

Structure:
1. Header strip (same as hub).
2. Breadcrumb strip — `--color-bg` background (recessed vs header), `--space-sm`
   vertical padding, 12px vertical padding.
3. Game title `<h1>` — Heading size, `--space-2xl` top margin.
4. Tool-card grid — same grid CSS as game cards, but tool card is simpler
   (no cover art; just tool name + short description line).

### Spawn-Timer Stub Page

Structure:
1. Header strip.
2. Breadcrumb strip.
3. Stub content area — vertically centered in remaining viewport, containing:
   - Tool name at Heading size.
   - Stub body copy (see Copywriting below).
   - No interactive controls.

### Breadcrumb Strip

Present on: game page, spawn-timer stub. NOT on hub landing (it is the root).

```
Game Tools Hub / Where Winds Meet / Spawn Timer
```

- Separator: ` / ` in `--color-text-secondary`
- Ancestor segments: `<a>` links, Label size, `--color-text-secondary`
- Active (current page) segment: Label size, `--color-accent` (jade), not a link
- Hover on ancestor links: `--color-text-primary` (no underline — color change is sufficient)
- Strip background: `--color-bg` (slightly recessed from header surface)
- Vertical padding: 12px top and bottom

## Favicon

Custom SVG favicon at `/favicon.svg`. Path in HTML: `<link rel="icon" href="/favicon.svg" type="image/svg+xml">`.

**Concept (Claude's discretion — D-10):** A stylized "GT" monogram (Game Tools) rendered
as a square badge. Left character "G" in `--color-text-primary` (#e8e4d8), right character
"T" in jade (#3fb98f). Background: #0f1115 rounded-rect. This reads clearly at 16px
favicon size, requires zero artistic skill to implement in SVG, and is game-agnostic
(no wuxia motif that would feel wrong if a non-wuxia game is added later).

SVG artboard: 32×32px viewBox. Filename: `/favicon.svg` (all-lowercase, root-absolute).

Fallback for browsers without SVG favicon support: none required (all modern browsers
support SVG favicons; GitHub Pages audience is developer/gamer, not IE11).

## Interaction States

| Element | Default | Hover | Focus | Active |
|---------|---------|-------|-------|--------|
| Game card | Surface bg, accent top-border | Surface-raised bg, full accent border | 2px focus ring `#3fb98f` offset 2px | Opacity 0.9 |
| Breadcrumb ancestor link | Secondary text, no underline | Primary text | 2px focus ring `#3fb98f` | — |
| Breadcrumb active segment | Accent text, not a link | — | — | — |

Transition: all hover state changes use `transition: 150ms ease`. No animation
beyond this in Phase 1.

Focus ring style (applied globally):
```css
:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: 2px;
}
```

## Responsive Breakpoints

Phase 1 targets basic responsiveness (THEME-04 is Phase 5, but shells must not break).

| Breakpoint | Width | Behavior |
|------------|-------|----------|
| Mobile | < 600px | Single-column card grid; page padding collapses to `--space-md` (16px) |
| Tablet+ | ≥ 600px | auto-fill grid kicks in; 24px gap; max-width 960px centered |

No JS needed for responsive behavior — CSS Grid `auto-fill` handles column count.

## Implementation Notes for Executor

1. `/shared/theme.css` is the ONLY style file for base tokens. Game pages `<link>` it
   first, then optionally a game-specific stylesheet for any overrides beyond the
   `data-game` attribute selector.

2. The `data-game` attribute on `<body>` is the accent override hook. Set it on every
   WWM page. Do not set it on hub landing.

3. All asset paths must be root-absolute (`/shared/theme.css`, `/favicon.svg`,
   `/games/where-winds-meet/cover.svg`). Never use relative paths.

4. All filenames must be all-lowercase. Enforce with `git config core.ignorecase false`
   before first commit.

5. `.nojekyll` must be the first file committed to the repo root.

6. The card renderer is an inline JS function on each hub/game page — not a shared
   module. This is intentional (CF-04): no fetch, no build step.
