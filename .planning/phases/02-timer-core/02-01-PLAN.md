<research_deviations>
RESEARCH.md refines two CLAUDE.md defaults — adopt the research where TIMER-08 and ALERT reliability require it:
1. The Web Worker owns the `setInterval` (escapes Chrome 88+ background-tab intensive throttling that delays main-thread timers to ~1/min). The main thread updates the DOM only on worker tick messages.
2. The cycle-end deadline is stored as a `Date.now()` epoch-ms timestamp, NOT `performance.now()` — because `performance.now()` resets on reload and cannot survive a refresh (reload survival lands in plan 02, but the deadline representation must be correct from the start). Drift-immune calculation: `remaining = cycleEnd - Date.now()`.
3. `OscillatorNode` is single-use — call `audioCtx.createOscillator()` fresh inside every beep (root cause of "silent after first cycle" bugs).
4. AudioContext is created/resumed inside the Start-button click gesture; iOS Safari adds an `interrupted` state, so resume on both `suspended` and `interrupted`, and on `visibilitychange` when visible.
</research_deviations>
