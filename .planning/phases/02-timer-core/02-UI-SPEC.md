# Phase 2 — UI Design Contract

> Visual and interaction contract for Phase 2: Timer Core (GvG spawn timer).
> Generated by gsd-ui-researcher. Consumed by gsd-planner, gsd-executor, gsd-ui-checker.

---

## Scope Note

This contract covers the **interactive spawn-timer tool** that replaces the Phase 1
stub at `/games/where-winds-meet/tools/spawn-timer/index.html`. It defines the
configuration inputs, the running countdown display, the control set, the
running/paused/finished state model, the cycle counter, the cycle-end alert flash,
and the mobile-first → capped-desktop responsive behavior.

It inherits the **entire Phase 1 design system unchanged**: all color, spacing, and
typography tokens are already defined in `/shared/theme.css` and MUST be reused as-is.
This phase introduces **zero new base tokens**. It adds only tool-specific component
styles (timer display, controls, config panel) layered on top of the existing tokens.

Out of scope (deferred): preset save/load UI (Phase 3), volume/mute and sound-pick
controls (Phase 4), wake lock and final touch-target hardening pass (Phase 5),
danger animation / progress ring / overtime (v2). Do not design or build those here.

## Typography

System font stack only. Three base roles inherited from `/shared/theme.css`, plus one
**tool-scoped display role** for the large countdown. The countdown is the only new
type treatment and reuses existing weights — no new font weights are introduced.

| Role | CSS Property / Scope | Size | Weight | Line Height | Usage |
|------|----------------------|------|--------|-------------|-------|
| Body | `--text-body` | 16px | 400 | 1.5 | Helper text, hints below inputs |
| Label | `--text-label` | 14px | 400 | 1.4 | Field labels ("Duration", "Repeat"), cycle counter |
| Heading | `--text-heading` | 20px | 600 | 1.2 | Tool `<h1>` "Spawn Timer", config section heading |
| Display (base) | `--text-display` | 28px | 600 | 1.1 | Reserved — site header title only |
| **Countdown (tool)** | tool-scoped, see below | **clamp 56px → 112px** | 600 | 1.0 | The large MM:SS countdown readable at arm's length |

**Countdown sizing (TIMER-05, THEME-05):**
```css
.timer__display {
  font-size: clamp(56px, 22vw, 112px);
  font-weight: 600;            /* reuses the existing 600 weight — no new weight */
  line-height: 1.0;
  font-variant-numeric: tabular-nums;   /* digits do not shift width as they change */
  letter-spacing: 0.02em;
  color: var(--color-text-primary);     /* #e8e4d8 on #0f1115 — ~14.1:1, AAA */
}
```

Font weights declared across the whole site remain exactly **400** (regular) and
**600** (semibold). The countdown uses 600. No third weight is introduced.

`font-variant-numeric: tabular-nums` is mandatory on the countdown and the cycle
counter so the layout does not jitter as digits tick.

## Color

Inherited verbatim from `/shared/theme.css`. No new base colors. The 60/30/10 split and
WCAG verification from Phase 1 carry forward unchanged.

| Role | Value | Usage in this phase |
|------|-------|---------------------|
| Dominant (60%) | `#0f1115` (`--color-bg`) | Page background, the area the large countdown sits on |
| Secondary (30%) | `#1a1d23` (`--color-surface`) | Config panel surface, control-bar background band |
| Surface raised | `#22262f` (`--color-surface-raised`) | Button hover, focused input background |
| Border | `#2a2e38` (`--color-border`) | Input borders, panel edges, control-bar top divider |
| Text primary | `#e8e4d8` (`--color-text-primary`) | Countdown digits, headings, button labels |
| Text secondary | `#9a9690` (`--color-text-secondary`) | Field labels, cycle counter, helper text, disabled-state text |
| Accent (10%) | `#3fb98f` jade (`--color-accent`) | See reserved list below |
| Destructive | `#d4af37` gold (`--color-accent-secondary`) | Reset control treatment ONLY (see note) — reset is non-destructive but distinct |

**Accent (jade `#3fb98f`) reserved for exactly:**
1. **Primary control = Start / Resume button** (filled jade background, `#0f1115` label text — see Controls below).
2. **Cycle-end alert flash** — the countdown digits flash jade for ~300ms at each cycle boundary (see Alert Flash below).
3. **Focus ring** on all interactive controls (already global: `:focus-visible { outline: 2px solid var(--color-accent) }`).
4. **Active/running state indicator** — a small jade state pip/text label next to the cycle counter while running.

Accent is NOT used for: countdown digits in their resting state, the page background,
the config panel surface, body/label text, input borders, or secondary buttons.

**Gold (`#d4af37`) note — there is no truly destructive action in this phase.** Reset is
recoverable (re-enter values). Reset therefore uses a **neutral secondary** button style
(outline on surface), NOT gold. Gold is held in reserve and unused as a button color in
Phase 2 to keep the 10% accent budget clean; it remains available for genuine destructive
actions in later phases (e.g. delete-preset confirm in Phase 3). The Destructive row above
documents the reserved token, not an element rendered this phase.

> Contrast check for the new filled jade button: label `#0f1115` on jade `#3fb98f`
> ≈ 6.3:1 → AA for normal text and AAA for large/bold button text. Pass.

## Layout Contracts

### Page Shell (unchanged from Phase 1)

Header strip → breadcrumb strip (`Game Tools Hub / Where Winds Meet / Spawn Timer`) →
`<main>` tool region → footer. Reuse `.site-header`, `nav[aria-label="Breadcrumb"]`,
and `.site-footer` from `/shared/theme.css` exactly. The breadcrumb renderer script
already present in the stub is retained.

### Tool Region — Mobile-First (375px baseline)

The `<main>` becomes the timer tool. On mobile (the primary use context — phone propped
as a second screen) the layout is a single vertical column filling the viewport:

Top-to-bottom inside `<main>`:
1. **Tool `<h1>` "Spawn Timer"** + subheading "GvG jungle spawn timer" — compact, top of region.
2. **Cycle counter** — Label size, secondary color, e.g. `Cycle 2 / 5` (or `Cycle 2 / ∞`).
3. **Countdown display** — the dominant element, vertically generous, near full-width,
   centered. This is what the user reads at arm's length.
4. **Config panel** — Duration input + Repeat input, stacked. Dimmed/disabled while running (see State Model).
5. **Control bar** — Start/Pause/Resume + Reset, pinned to the thumb zone near the
   viewport bottom (`--space-md` bottom inset). Large 44px+ targets.

```css
.timer {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: var(--space-lg);
  padding: var(--space-md);
  min-height: calc(100vh - 200px);   /* fill viewport below header+breadcrumb */
}
.timer__display { /* clamp sizing per Typography */ }
.timer__controls {
  display: flex;
  gap: var(--space-sm);
  width: 100%;
  margin-top: auto;                  /* push to bottom thumb zone on mobile */
  padding-bottom: var(--space-md);
}
```

### Tool Region — Desktop (≥ 1280px, capped)

The same vertical column is **centered and width-capped at ~480px**; it does NOT span
the full desktop viewport. The countdown stays large but is no longer edge-to-edge.

```css
@media (min-width: 768px) {
  .timer {
    max-width: 480px;
    margin-inline: auto;
    padding: var(--space-xl);
    gap: var(--space-2xl);
  }
  .timer__controls {
    margin-top: 0;                   /* no longer pinned to bottom; natural flow */
    padding-bottom: 0;
  }
}
```

(The 768px breakpoint applies the capped-panel treatment for tablet and up; at 1280px+
it is simply the same centered 480px panel with desktop padding. The countdown `clamp()`
ceiling of 112px keeps it readable but bounded inside the 480px panel.)

### Config Panel

A `--color-surface` panel containing two labeled fields:

| Field | Label | Input | Notes |
|-------|-------|-------|-------|
| Duration | "Duration" | text input accepting `MM:SS` or raw seconds | placeholder `e.g. 3:00 or 180`; helper line under it: "MM:SS or seconds" |
| Repeat | "Repeat" | number input + an "Unlimited" toggle/checkbox | when Unlimited is on, the number input is disabled and the total renders as `∞` |

- Panel: `--color-surface` bg, 1px `--color-border`, 8px radius, `--space-md` padding,
  `--space-md` gap between fields.
- Labels: Label size, `--color-text-secondary`, sit above their input with `--space-xs` gap.
- Inputs: `--color-bg` background, 1px `--color-border`, `--color-text-primary` text,
  minimum 44px height, `--space-md` horizontal padding, 6px radius.
- Input focus: border shifts to `--color-accent`; global focus ring also applies.

### Controls

| Control | Style | State availability |
|---------|-------|--------------------|
| Start | Filled jade (`--color-accent`) bg, `#0f1115` label, 600 weight | Shown in idle/finished states |
| Pause | Neutral secondary — `--color-surface-raised` bg, `--color-text-primary` label, 1px `--color-border` | Shown while running |
| Resume | Filled jade (same as Start) | Shown while paused |
| Reset | Outline — transparent bg, 1px `--color-border`, `--color-text-secondary` label | Shown whenever timer is non-idle (running, paused, finished) |

- All buttons: minimum 44px height, `--space-md` horizontal padding, 6px radius,
  `transition: background 150ms ease, border-color 150ms ease`.
- Primary (Start/Resume) hover: slightly lifted jade (use `filter: brightness(1.08)` —
  no new color token). Active: `opacity: 0.9`.
- Secondary/outline hover: background → `--color-surface-raised`.
- Start/Resume occupy the primary (wider / left) slot; Reset is the trailing slot.
  Pause replaces Start in the primary slot while running.

## State Model (running / paused / finished) — TIMER-07

Four logical states. The component toggles a `data-state` attribute on the timer root
(`idle | running | paused | finished`) and CSS keys off it. State drives display color,
control visibility, and config-panel interactivity.

| State | Countdown digits | Cycle counter | Config panel | Visible controls | State signal |
|-------|------------------|---------------|--------------|------------------|--------------|
| idle (config) | shows configured duration, primary color, static | hidden or shows `Cycle 1 / N` preview | **full opacity, editable** | Start | none |
| running | ticking, primary color; flashes jade at each cycle end | `Cycle X / N`, secondary color + jade running pip | **40% opacity, disabled (read-only reminder)** | Pause, Reset | jade pip / "Running" |
| paused | frozen at current value, primary color | `Cycle X / N` unchanged | **40% opacity, disabled** | Resume, Reset | secondary-color "Paused" label, no pip |
| finished | `0:00` (or last cycle end), primary color | `Cycle N / N` (or count reached) | **full opacity, editable** | Start, Reset | secondary-color "Finished" label |

**Config panel dimming (locked decision Q3):** While `data-state="running"` or
`"paused"`, the config inputs remain visible but disabled at **40% opacity**, serving as
a clearly-locked reminder of the active configuration. They return to full opacity and
become editable again in `idle` and `finished`.

```css
.timer[data-state="running"] .timer__config,
.timer[data-state="paused"]  .timer__config {
  opacity: 0.4;
  pointer-events: none;
}
.timer__config :is(input, button, [type="checkbox"]):disabled { cursor: not-allowed; }
```

The disabled state is also enforced on the inputs themselves via the `disabled` attribute
(opacity is the visual reminder; `disabled` is the real interaction lock and the a11y signal).

**State label / pip** sits inline with or just under the cycle counter:
- running: small jade dot (8px) + no text needed, OR text "Running" in jade.
- paused: text "Paused" in `--color-text-secondary`, no pip.
- finished: text "Finished" in `--color-text-secondary`.

## Cycle-End Alert Flash — ALERT-01, locked decision Q1

When a cycle reaches zero and the beep fires, the countdown digits flash **jade
(`#3fb98f`) for ~300ms**, then the next cycle begins immediately. The flash is a brief
accent flash on the **time display only** — NOT a held color change and NOT a full-panel
pulse. It is a secondary, subtle reinforcement of the audible beep (the beep is the
primary signal).

```css
@keyframes timer-flash {
  0%   { color: var(--color-text-primary); }
  20%  { color: var(--color-accent); }      /* jade peak early */
  100% { color: var(--color-text-primary); }
}
.timer__display.is-flashing {
  animation: timer-flash 300ms ease-out;
}

/* Reduced-motion gate (mandatory): suppress the flash entirely.
   The beep remains the signal; the cycle simply advances. */
@media (prefers-reduced-motion: reduce) {
  .timer__display.is-flashing { animation: none; }
}
```

**Reduced-motion contract (locked):** Under `prefers-reduced-motion: reduce`, the flash
is fully suppressed — no color animation. The audible beep still fires and the cycle
advances normally. The flash is purely additive reinforcement, never the sole indicator.

The JS toggles `.is-flashing` at the cycle boundary and removes it on `animationend`.

## Responsive Breakpoints

Mobile-first. The 375px column is the baseline; desktop caps the panel.

| Breakpoint | Width | Behavior |
|------------|-------|----------|
| Mobile (baseline) | 320–767px (designed at 375px) | Single full-width column; countdown near full-viewport via `clamp(56px, 22vw, 112px)`; controls pinned to bottom thumb zone with 16px inset; config panel full-width |

this phase must already avoid horizontal overflow at 375px). No JS is needed for the

## Accessibility Notes (THEME-05)

- Countdown digits `#e8e4d8` on `#0f1115` ≈ 14.1:1 → AAA. Tabular numerals prevent jitter.
- Cycle counter / labels `#9a9690` on `#0f1115` ≈ 4.9:1 → AA.
- Jade primary-button label `#0f1115` on `#3fb98f` ≈ 6.3:1 → AA (AAA at button text size).
- State changes are conveyed by **text label + control change**, not color alone
  (the running pip is supplemented by control-set changes and the cycle counter advancing).
- The cycle-end flash is gated behind `prefers-reduced-motion: reduce`; the beep is the
  primary, non-visual signal so the alert never depends on motion or color alone.
- All controls and inputs meet the 44px touch-target floor.
- Disabled inputs use the real `disabled` attribute (not just opacity) so assistive tech
  announces them as unavailable while running.

## Implementation Notes for Executor

9. Asset/style paths root-absolute; filenames all-lowercase (Phase 1 convention).
10. Timer engine accuracy/Web-Worker drift correction is a planner/executor concern
    (TIMER-08); this contract governs only the visual + interaction surface.
