# Sketch Manifest

## Design Direction
The Game Tools Hub is a dark-themed, statically-hosted (GitHub Pages) collection of companion
tools for video games — a hub that lists supported games, each with its own page of tools. The
first game is *Where Winds Meet* and the first tool is a GvG jungle spawn timer. The core value
is that a hosted tool works reliably in the browser during real gameplay. The redesign explores
two visual identities before migrating to Eleventy + Nunjucks + Tailwind v4: an **Elevated Wuxia**
direction that evolves the existing jade/gold ink palette into something premium and calm, versus
a **Bolder Neon Gamer** direction with esports-dashboard energy, Fira mono type, and live readouts.

## Reference Points
- Existing production identity: `index.html` + `shared/theme.css` (jade `#3fb98f`, gold `#d4af37`,
  ink `#0f1115`, parchment `#e8e4d8`).
- ui-ux-pro-max design-system output: dark bg + green positive indicators, Fira Code/Fira Sans,
  vibrant block-based style for gaming products.
