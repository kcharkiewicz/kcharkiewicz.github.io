# Sketch 001: Landing Direction

## Design Question
Which visual identity should the hub commit to before the Eleventy + Tailwind migration?
Both keep the same content (hero + one game card with room to grow) so only the visual
treatment differs.

## How to View
open .planning/sketches/001-landing-direction/index.html

Switch directions with the tabs at the top. Use the bottom-right toolbar to preview at
375 / 768 / 1280 / full width.

## Variants
- **A: Elevated Wuxia** — keeps the existing jade `#3fb98f` + gold `#d4af37` on dark ink. Cinzel
  serif display, Inter body. Ink-wash radial gradients, gold filigree divider, breathing jade
  seal, calm premium spacing. Evolves the current identity rather than replacing it.
- **B: Bolder Neon Gamer** — near-black `#020617` with a faint grid, neon teal/cyan edges,
  Fira Code headings + Fira Sans body. Stats strip, glowing cards, a live ticking mock spawn
  readout on the game card. Esports-dashboard energy.

## What to Look For
- Which one feels right *for a tool you'd open mid-match* — calm and legible, or punchy and live?
- Does the wuxia serif read as premium or too soft for a utility?
- Does the neon glow read as energetic or too noisy/distracting?
- The neon card previews the actual product (a spawn timer) on the card face — worth keeping?
- Cherry-picking is fine: e.g. "wuxia palette + neon's live-timer card face."
